# 🖼️ Landing page & Museum

## 🌟 About the project

This project is a modern, responsive landing page for an art museum. Designed with clarity and elegance in mind, it showcases key sections such as exhibitions, gallery, events, and contacts. The page follows clean code principles and uses structured SCSS based on the BEM methodology.

## 🚀 Technologies Used

✅ **HTML5** – semantic markup of the page.

✅ **SCSS (Sass)** – preprocessor that allows for nesting, variables, mixins, and modularity.

✅ **BEM (Block Element Modifier)** – CSS architecture methodology for maintainable code.

✅ **Parcel** – ultra-fast bundler for development and production.

✅ **Linters** – ESLint, Stylelint, and Prettier were used to maintain code consistency and quality.
